# java-calculator-precourse

## 기능 목록

### 문자열 입력

- 입력값이 비어있거나 공백이면 0으로 처리
- "//"와 "\n" 사이에 구분자를 확인
  - 예외) "//"와 "\n" 사이에 공백이거나 비어있으면 예외처리
  - 예외가 발생한 경우 프로그램을 종료
- 커스텀 구분자를 기본 구분자로 치환
- 기본 구분자를 기준으로 숫자를 분리
  - 예외) 분리한 숫자가 int가 아니면 예외처리
  - 예외) 양수가 아니면 예외처리
  - 예외가 발생한 경우 프로그램을 종료


### 계산

- 숫자들의 합을 계산
- 덧셈 결과를 출력하고 프로그램을 종료
